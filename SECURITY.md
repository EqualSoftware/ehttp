# Security policy

## Report a vulnerability

Report a vulnerability with GitHub private vulnerability reporting:

1. Open https://github.com/EqualSoftware/ehttp/security.
2. Select **Report a vulnerability**.
3. Describe the problem. Include the steps to reproduce it and the versions
   that you tested.

Do not open a public issue or a pull request for a vulnerability.

## Supported versions

Only the latest release gets security fixes.
